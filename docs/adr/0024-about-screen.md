# 0024. Экран "О приложении" — автор, лицензия, краткое руководство

## Контекст

У приложения не было ни одного места, где было бы видно, кто автор, на
каких условиях распространяется код, и как вообще пользоваться менее
очевидными функциями (сопряжение только внутри профиля vs "Поделиться",
"Ждать сопряжения" и т.п.) — README и `docs/` не помогают тому, кто
просто открыл установленное приложение.

## Решение

Новый `AboutScreen` (`lib/features/about/about_screen.dart`) — чисто
статический экран, ничего не читает из провайдеров/репозиториев:

- Имя, версия (через `package_info_plus` — платформенно из
  `pubspec.yaml`, не дублируется вручную), автор ("zaigard"), лицензия
  (PolyForm Noncommercial 1.0.0, коротко своими словами + отсылка на
  `LICENSE.md`).
- "Как пользоваться" — пять разворачиваемых (`ExpansionTile`) разделов:
  Библиотека, Плейлисты, Устройства и сопряжение, "Поделиться",
  Профили. Текст — по сути сжатый пересказ того же, что уже описано в
  README/ADR, но для человека, который открыл приложение, а не
  репозиторий.

Точка входа — иконка "ⓘ" в `AppBar` вкладки "Устройства": у приложения
нет отдельной вкладки настроек, а "Устройства" уже ближе всего к этой
роли (там же карточка профиля/переключатель). Пуш через
`Navigator.push(MaterialPageRoute(...))` — тот же паттерн, что уже
используют "Избранное"/"Удалённые" из `PlaylistsScreen`.

## Последствия

- Новая зависимость `package_info_plus` — только для чтения версии,
  разрешений не требует.
- Чисто UI, без unit-тестов — статический контент, живая проверка как
  и весь остальной UI-слой проекта.
