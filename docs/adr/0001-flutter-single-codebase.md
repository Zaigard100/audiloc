# 0001. Flutter как единственный стек для Linux/Windows/Android

## Контекст

ТЗ требует один UI на трёх платформах (Linux, Windows, Android) с
нативной производительностью, тёмной темой и мини-плеером в стиле
Яндекс Музыки. Альтернативы: Electron (веб-стек, тяжёлый рантайм,
посредственная нативность на Linux/Windows), нативные приложения на
каждую платформу отдельно (три кодовые базы, кратный рост стоимости
поддержки), .NET MAUI (слабая поддержка Linux).

## Решение

Flutter — единственный кандидат, дающий один Dart-код на все три
платформы без компромиссов по UI, с рисованием через Skia/Impeller
(независимо от платформенных тулкитов) и зрелой экосистемой пакетов
под ровно те задачи, которые нужны (см. 0002–0007).

## Последствия

- Один язык (Dart), один UI-слой, одна кодовая база бизнес-логики.
- Требует системных зависимостей на Linux для десктоп-сборки
  (см. README «Установка») и Android SDK для мобильной — в этой
  разработческой среде проверена только Linux-сборка (нет Android
  SDK), см. docs/roadmap.md.
- Виджет-тесты не требуют платформенных биндингов вообще — только
  `flutter test`, что упростило тестирование без Android/Windows.
